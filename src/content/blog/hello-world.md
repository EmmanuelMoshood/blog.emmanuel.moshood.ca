Every engineer I admire keeps some kind of public notebook. This is mine.

I work in the space between writing software and running it: CI/CD pipelines, infrastructure as code, Kubernetes, observability, and — more and more — the tooling that gets machine-learning models into production safely.

## What to expect

- **Hands-on notes.** Things I've built or broken, with the config and commands that actually worked.
- **Learning in public.** Certifications, courses, and books, with honest takeaways.
- **Career reflections.** How roles in DevOps, platform and MLOps differ, and what I'm learning about each.

## Why write at all?

Writing forces clarity. If I can't explain why a pipeline is shaped the way it is, I probably don't understand it yet.

If any of this is useful to you, subscribe via [RSS](/rss.xml). Thanks for reading.
